# ADR-0001 — Rust for the core and CLI; Python only as a binding and for the bench

- Status: accepted (2026-10-06)
- Deciders: Matias Molinas

## Context

agentvcs today is ~7.8k lines of stdlib-only Python (see `docs/INVENTORY.md`).
The revival turns it into the substrate under live hot-patching: every step of a
long run is stamped with the harness version that produced it, so `step record`
sits on the hot path of somebody else's harness, and the ledger is the evidence a
result rests on.

## Decision

- Core, CLI and MCP server are written in Rust (Cargo workspace under `crates/`).
  - The compiler and type system act as a verifier over agent-written code,
    consistent with the org's verifier-gated approach.
  - One static binary, no runtime, for macOS arm64 and Linux x86_64.
  - Hashing, an append-only ledger and structural diff are systems work.
  - Embeddable in any harness.
- The Python SDK is a thin PyO3/maturin binding. It does not reimplement logic.
- Migration is gated by conformance, not big-bang:
  1. Freeze the protocol spec (`spec/`, JSON Schema + golden files).
  2. Run the current Python implementation against the conformance suite and
     record where it differs (expected: almost everywhere — it predates v0.1).
  3. Write the Rust core against the same suite.
  4. When Rust passes 100%, move the Python implementation to `legacy/`; delete it
     in the following release.
- **The bench does not wait for Rust.** If by week 2 the Rust core does not pass
  conformance, the bench runs on a Python implementation behind the same CLI/SDK
  interface. The validation calendar outranks the migration.

## Consequences

- Two implementations coexist for one release. The conformance suite is the
  single source of truth between them; neither is the reference.
- The goldens are generated by `conformance/tools/gen.py`. To keep the generator
  from becoming an unexamined reference, the suite also carries externally
  published vectors (RFC 8785 examples, the BLAKE3 empty-input digest) that no
  code of ours produced.
